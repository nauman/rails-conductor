# Use Kuickr for Visual Review

## Rule

Use Kuickr whenever Conductor work benefits from a visual companion, including
mockups, diagrams, comparisons, and interactive decision surfaces. Do not ask
the operator to choose a different visual-review tool each session.

Textual requirements and technical decisions can stay in the conversation.
When an artifact becomes visual, publish or open it through the repository's
existing Kuickr workflow.

## Source

Operator preference, confirmed 2026-07-31: “use always kuickr”.
